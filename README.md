# **About Me**

Hi! I'm **Valentín**, a full-stack software developer passionate about building scalable, clean, and efficient systems. I specialize in **backend engineering** with **Java & Spring Boot**, **SQL**, **REST/GraphQL APIs**, and also develop modern frontend applications using **React, TypeScript, and Angular**.

I love solving complex problems through solid software engineering principles, data structures, and algorithms.

---

## **What I’m Currently Working On**

* Developing **Java + Spring Boot microservices** using JPA/Hibernate
* Designing and integrating **REST & GraphQL APIs**
* Building **full-stack applications** with React, TypeScript, and Node.js
* Working with **MySQL, PostgreSQL, MongoDB**
* Implementing **CI/CD pipelines** (GitLab) and automated testing (JUnit, TestNG)
* Studying **distributed systems**, cloud architecture, and scalable backend design
* Freelancing under **Carlomagno Web Services** (web dev, design & video editing)
* Practicing advanced algorithms:

  * Graphs, DFS/BFS
  * Greedy & backtracking
  * Hash structures
  * Binary search trees (BST)
